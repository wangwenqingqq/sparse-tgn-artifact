# FlashTGN / TGN 优化实验记录

本仓库归档截至 2026-09-11 的研究代码、报告、图表、计时记录与独立验证结果。2026-09-20 整理用于 GitHub 保存；本次整理没有重新运行 GPU 实验。

项目基线是 **FlashTGN**。早期 TNCN 实验属于内部消融，其加速比不能解释为相对 FlashTGN 的收益。目前尚未建立相对 FlashTGN 的端到端加速或完整训练质量等价结论。

## 主要结果

|实验|已观察到的结果|适用范围|
|---|---|---|
|FlashTGN W_kv 局部原型|修正空查询语义后，12 组固定输入的局部输出和梯度检查通过；六组实际改变的输入全部变慢，局部配对速度几何平均为 0.644×，对应耗时增加约 55.2%|停止扩大当前“压缩→投影→展开”实现；不能据此排除其他 W_kv 优化|
|FlashTGN 固定反向输入重放|192/192 次满足原定数值容差，但不是逐字节确定|局部噪声测量；没有解决完整训练的数值一致性问题|
|FlashTGN 基线诊断|完成 96 个完整训练 epoch 的计时、16 个 epoch 的阶段剖析和 8 个中部步骤的内核 trace；mailbox 写入占整轮约 0.4%–2.2%，backward 约 39.1%–52.7%|当前 artifact 的连续训练数值门槛未通过，因此仅作诊断数据|
|消费者布局原生验证|指定输入下正确；Blackwell 上相对优化后的普通布局约 1.00×，未观察到额外收益|B1 实际展开为 IMMA；不能外推为原生 BMMA 的普遍结论|

## 代码、数据与复现范围

`tgn_sparsebit_review_20260908/` 保留本地已有的代码、源码快照、报告、图表、日志、独立审计、校验清单和部分小型张量证据。各实验目录中的 `CONTRACT.md`、`AMENDMENT*.md`、`ATTEMPTS.md` 和 `REPRODUCE.md`（存在时）说明固定条件、修改原因、失败尝试与运行方法。失败结果同样保留。

大型原始张量留在原实验服务器。本次 W_kv 实验的 108 份原始输入/输出合计 113,786,299,246 字节；它们的哈希、大小与独立 CPU 审计记录随仓库保存。其他实验也通过各自的 `remote_manifest.json`、`transfer_verification.json` 和 `closure.json` 说明本地与远程材料的边界。克隆本仓库不会自动获得这些远程数据。

多数运行脚本记录了原实验环境的绝对路径。重新执行 GPU 实验前，需要配置相应的源码、依赖、数据与可用设备，并使用新的输出目录。仓库中的来源快照不代表已经验证其官方 Git 提交；FlashTGN 源副本缺少 Git 元数据，该限制保留在原报告中。

`PUBLISH_MANIFEST.sha256` 校验此次发布的文件；各实验自己的 `MANIFEST.sha256` 保持原样。发布时仅排除 Python 字节码缓存。原始上传的长对话材料与报告中引用的外部目录不属于此次本地成果快照。
